# Removal

This add-on writes no world, player, or required configuration state. Remove
only its JAR from `config/bluemap/packs`, restart BlueMap's JVM, and rerender
affected regions if stock output is desired.

No legacy All the Mons 1.1.1 profile, migration, or fallback artifact is
maintained. An exact-profile mismatch already keeps Pipez on BlueMap's
original resource path.
